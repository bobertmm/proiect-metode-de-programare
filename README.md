# RO:

Acest proiect are ca scop prezentarea metodelor de programare backtracking, greedy, divide et impera și programare dinamică în C++ prin intermediul unui site. Pentru a face asta vom prezenta câte o problemă ușoară pentru fiecare metodă, a cărei soluție o vom explica, o vom ilustra printr-un GIF animat și vom atașa un exemplu de cod sursă care rezolvă problema respectivă.

# EN:

This project's purpose is to present the following programming methods in C++: backtracking, greedy, divide et impera and dynamic programming. To do this we will provide a coding task for each method, which we will explain the solution of, illustrate it through an animated GIF and attach a source code example which solves said task.
