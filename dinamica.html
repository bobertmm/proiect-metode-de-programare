Frog 2

Avem N pietre, numerotate de la 1-N. Pentru fiecare piatră i (1 ≤ i ≤ N), inălțimea pietrei i este hi. O broască se află inițial pe piatra 1. Va repeta următoarele actiuni de un număr de ori până când ajunge pe piatra N: Daca broasca se află pe piatra i, poate să sară pe una dintre pietrele următoare: piatra i+1, i+2, ..., i+k. Costul unei sarituri este dat de înălțimea pietrei de pe care sare minus înălțimea pietrei pe care aterizeaza |hi - hj|. Găsiți costul total minim astfel încât broasca să ajungă pe piatra N.

Pentru parcurgerea în spate, funcția calculare_dp ia fiecare poziție (să îi spunem poziția i) și se uită în spate la pozițiile din care putea să ajungă acolo. Observăm că acestea sunt ultimele k pietre, sau dacă sunt mai puțin de k pietre în urmă, atunci le vom lua pe toate aceastea. Pentru fiecare dintre aceste pietre (să le spunem "pietre posibile") vom calcula costul de ajungere în piatra i din piatra posibilă ca fiind costul săriturii din piatra posibilă în i + costul de ajungere în piatra posibilă. Vom compara costurile obținute astfel și vom lua minimul, pe care îl vom salva în dp[i] (adică în dp[i] vom avea costul minim de ajungere de la început la poziția i). La sfârșit vom afișa dp[n], adică costul minim de ajungere pe piatra n de pe piatra 1.

Pentru parcurgerea în față, va fi necesar să inițializăm valorile din dp cu un număr foarte mare, pentru a putea face minimul. Apoi pentru fiecare piatră (să îi spunem piatra i) ne uităm la pozițiile în care putem ajunge din aceasta (să le spunem "poziții posibile"). Pozițiile posibile vor fi următoarele k dacă mai sunt destule în față, dacă sunt mai puține le luăm pe toate. Calculăm costul de ajungere din piatra i în piatra posibilă astfel: costul de ajungere în i + costul săriturii din i în poziția posibilă. Apoi calculăm dp[poziție posibilă] ca fiind minimul dintre: valoarea pe care o are acum și costul de ajungere din i în piatra posibilă.

Exemplu de cod cu parcurgere în spate


#include <iostream>

using namespace std;

const int NMAX = 1e5;
const int INF = 1e9;

int n, k;
int h[NMAX + 1];
int dp[NMAX + 1];

void citire(){
    cin >> n >> k;
    for (int i = 1; i <= n; ++i){
        cin >> h[i];
    }
}

int cost(int a, int b){
    return abs(h[a] - h[b]);
}

void calculare_dp(){
    for (int i = 2; i <= n; ++i){
        int mini = INF;
        for (int j = i - 1; j >= max(i - k, 1); --j){
                int cost_curent = cost(i, j) + dp[j];
                if (cost_curent < mini)
                    mini = cost_curent;
        }
        dp[i] = mini;
    }
}

void afisare(){
    cout << dp[n];
}

int main()
{
    citire();
    calculare_dp();
    afisare();
    return 0;
}

Exemplu de cod cu parcurge în față


#include  <iostream>

using namespace std;

const int NMAX = 1e5;
const int INF = 1e9;

int n, k;
int h[NMAX + 1];
int dp[NMAX + 1];

void citire(){
    cin >> n >> k;
    for (int i = 1; i <= n; ++i){
        cin >> h[i];
    }
}

int cost(int a, int b){
    return abs(h[a] - h[b]);
}

void init_dp(){
    for (int i = 2; i <= n; ++i){
        dp[i] = INF;
    }
}

void calculare_dp(){
    for (int i = 1; i < n; ++i){
        for (int j = i + 1; j <= min(i + k, n); ++j){
            int cost_curent = cost(i, j) + dp[i];
            if (cost_curent < dp[j]){
                dp[j] = cost_curent;
            }
        }
    }
}

void afisare(){
    cout << dp[n];
}

int main()
{
    citire();
    init_dp();
    calculare_dp();
    afisare();
    return 0;
}
